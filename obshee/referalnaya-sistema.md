# Реферальная система

<mark style="color:$primary;">Реферальная система</mark> - система поддержки игроков приглашающих друзей в игру и будущих креаторов сервера!&#x20;

{% hint style="info" %}
Обратите внимание, что код можно ввести всего один раз!
{% endhint %}

**Новые игроки могут получить бонусы в виде -**&#x20;

* <mark style="color:$primary;">10 Е-койнов при введении кода</mark> (зачисляется после 3х часов игры)
* <mark style="color:$primary;">2 Е-койна каждый PayDay</mark> (Подробнее - [#payday](../goroda/gorodskie-komandy/drugie-mekhaniki.md#payday "mention"))

**Владелец кода получит бонус в виде -**

* <mark style="color:$primary;">2 Очка активности каждый день</mark> за каждого приглашённого игрока, которые находятся в вашем городе
* <mark style="color:$primary;">20% от полученных Е-койнов игроком</mark>, который ввёл код, при условии, что он получил 5 PayDay

### Как ввести реферальный код?

Чтобы ввести реферальный код другого игрока, пропиши команду <mark style="color:$primary;">/ref use <Код игрока></mark>. После соблюдения условий, тебе начислят бонусы!

### Как получить свой реферальный код?

Собственный реферальный код можно получить после того, как ты заработал <mark style="color:$primary;">30 PayDay</mark>

Чтобы посмотреть текущее количество и собственный код в будущем, пропиши команду <mark style="color:$primary;">/ref status</mark>

### Другие команды и возможности

<mark style="color:$primary;">На основном спавне</mark> (/spawn), а так же по команде <mark style="color:$primary;">/ref top</mark>, ты можешь посмотреть топ игроков по количеству введённых кодов. Эти коды так же можно вводить, но имей в виду, что код можно ввести всего один раз!
