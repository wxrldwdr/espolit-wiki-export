# Префиксы

<mark style="color:$primary;">**Префикс**</mark> — это короткая приписка перед твоим ником в чате, которая поможет выделяться среди других и подчеркнуть твой политический образ!

Чтобы выбрать один из таких, нужно прописать команду <mark style="color:$primary;">/prefix</mark>

{% hint style="info" %}
Префикс отображается **в сообщениях чата, над головой, и в некоторых каналах чатов**
{% endhint %}

{% stepper %}
{% step %}
#### Пропиши команду <mark style="color:$primary;">/prefix</mark>
{% endstep %}

{% step %}
#### В меню префиксов выбери <mark style="color:$primary;">"Префиксы сезона"</mark>

<figure><img src="../../.gitbook/assets/image (194).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Выбери любой доступный префикс!

<figure><img src="../../.gitbook/assets/image (195).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Префиксы выдаются случайно, в качестве награды, или за выполнение определённых достижений! После выполнения заданий горожанина в <mark style="color:$primary;">/guide</mark>, ты уже можешь получить один из таких!

А купить случайный префикс вы можете на нашем сайте - [<mark style="color:$primary;">espolit.ru</mark>](https://espolit.ru)

И помните, <mark style="color:$primary;">префиксы меняются каждый сезон</mark>, поэтому если понравился какой-то префикс, лучше приобрести его <mark style="color:$primary;">сейчас</mark>!



### Меню префиксов

Кроме просмотра префиксов сезона, в меню вы можете переключить отображение префиксов, а так же посмотреть текущие префиксы. Вне зависимости от сезона, купленный Вами префикс <mark style="color:$primary;">будет Ваш навсегда</mark>!&#x20;
