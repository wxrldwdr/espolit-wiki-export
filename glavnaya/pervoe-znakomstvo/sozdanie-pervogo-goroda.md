# Создание первого города

Для создания города необходимо собрать нужное количество ресурсов, выбрать территорию, и находясь на территории прописать <mark style="color:$primary;">**/t new <Название города>**</mark>

<figure><img src="../../.gitbook/assets/image (161).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Если по команде <mark style="color:$primary;">**/guide**</mark> пройти обучение новичка, по завершению выдаст необходимые ресурсы для города
{% endhint %}

<figure><img src="../../.gitbook/assets/image (222).png" alt=""><figcaption></figcaption></figure>

Когда все необходимые ресурсы будут в Вашем инвентаре, а так же пропишите команду для создания города, в чате появится подтверждение. Нажмите <mark style="color:$primary;">"Продолжить"</mark> чтобы списать ресурсы и создать город.

{% hint style="warning" %}
Помните, название города не должно содержать рекламы/оскорблений/лозунгов!
{% endhint %}
