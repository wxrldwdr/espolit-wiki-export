### <mark style="color:$primary;">Обновление 04.05.2026</mark>

<details>

<summary><mark style="color:$primary;">Подробности обновления сервера</mark></summary>

1\) Добавлены кейсы на /spawn. <mark style="color:$primary;">Подробнее:</mark> [keisy.md](pervoe-znakomstvo/keisy.md "mention")

2\) Добавлены ТОПы городов и игроков по различным параметрам в виде голограмм на <mark style="color:$primary;">/spawn</mark>.

3\) Добавлен раздел /cshop <mark style="color:$primary;">Подробнее:</mark> [magaziny.md](../obshee/drugie-vozmozhnosti/magaziny.md "mention")

`Так же обновлены механики. Основные изменения:`

* `Для создания/редактирования магазина дополнительно возможно использовать команду`` `<mark style="color:$primary;">`/shop`</mark>
* `Для`` `<mark style="color:$primary;">`создания/редактирования`</mark>` ``магазина дополнительно возможно сочетание клавиш`` `<mark style="color:$primary;">`SHIFT+ПКМ`</mark>
* `Возможность выбирать минимальное количество покупаемых ресурсов`
* `Улучшен интерфейс для выбора количества ресурсов`
* `Добавлена`` `<mark style="color:$primary;">`механика скидок`</mark>` ``для игроков в своём городе и альянсов, скидка за оптовую покупку, а так же наценка для врагов города`

4\) Улучшен <mark style="color:$primary;">AFK менеджер</mark>, добавлено больше надписей, а так же, за открытие всех надписей можно открыть секретный префикс, который нельзя получить случайно

5\) Добавлена механика набора рейтинга - <mark style="color:$primary;">Пейдей</mark>. Подробнее: [#payday](../goroda/gorodskie-komandy/drugie-mekhaniki.md#payday "mention")

6\) Добавлена механика реферальной системы. Подробнее: [referalnaya-sistema.md](../obshee/referalnaya-sistema.md "mention")

7\) Улучшение городского инвентаря

`Основные изменения:`

* `Теперь в`` `<mark style="color:$primary;">`/t grow`</mark>` ``можно прокачать количество страниц инвентаря`
* `Любая оплата ресурсами изымается с любых страниц`
* `Из инвентаря доступен быстрый переход в Городской склад`
* `Из инвентаря доступна оплата налога`
* `Из инвентаря доступен режим отображения`` `<mark style="color:$primary;">`Целей`</mark>

8\) Добавлена механика <mark style="color:$primary;">Целей</mark>. Подробнее: [#celi](../goroda/gorodskie-komandy/razvitie-goroda.md#celi "mention")

9\) Рейтинг переименован в <mark style="color:$primary;">Очки Активности</mark> для большей понятности

10\) Оплата налогов, Создание города, Ресурсы для Городских построек и Освоения, Городские квесты, Общие квесты, теперь засчитывают несколько ресурсов/мобов

* `Теперь создание города и оплата налогов требует любое дерево`
* `Городские квесты и общие квесты засчитывают разные виды ресурсов (Пример: Алмазная руда и Глубинная алмазная руда)`
* `Городские квесты и общие квесты засчитывают разные виды мобов (Пример: Зомби и Зомби житель)`

11\) Обновления <mark style="color:$primary;">Веков</mark>

`Основные изменения:`

* `Для прокачки века теперь требуется всего один из доступных параметров`
* `Территориальные претензии теперь привязаны к векам`
* `Количества альянсов теперь привязаны к векам`
* `Городской налог увеличивается с каждым прокачанным веком`
* `При прокачке века добавляется количество Очков Активности`

12\) Городские постройки (<mark style="color:$primary;">/t builds</mark>)

`Основные изменения:`

* `Постройки низкого уровня больше не требуют рейтинг`
* `Добавлена кнопка "Назад" из ветки Построек в основное меню`
* `Исправлен баг, когда при прокачке Постройки можно было получить ресурсы из следующего уровня по истечению таймера`

13\) Освоение (/t grow)
