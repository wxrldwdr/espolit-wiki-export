SURWAVE WIKI — локальная версия ESPOLIT-контента в новой стилистике

ЗАПУСК
1. Установи Python 3, если его нет.
2. Запусти START_WIKI.bat.
3. Скрипт автоматически:
   - читает SUMMARY.md;
   - находит все остальные .md страницы;
   - превращает их в отдельные HTML;
   - копирует ВСЮ папку .gitbook/assets без пережатия;
   - исправляет относительные внутренние ссылки;
   - запускает локальный HTTP-сервер;
   - открывает Wiki в браузере.

СБОРКА БЕЗ ЗАПУСКА
BUILD_WIKI.bat
Готовая статическая версия появится в surwave-site/dist/.

ЧТО РЕДАКТИРОВАТЬ
- Исходные страницы: Markdown-файлы в корне репозитория и его разделах.
- Исходные картинки/медиа: .gitbook/assets/
- Цвета/внешний вид: surwave-site/assets/css/site.css
- Поведение интерфейса: surwave-site/assets/js/site.js
- Логотип: surwave-site/assets/logos/surwave-wiki-logo.svg

ВАЖНО
Папка dist генерируется автоматически. Редактировать HTML внутри dist вручную не нужно: изменения будут перезаписаны при следующем запуске START_WIKI.bat.

Поддерживаются обычный Markdown и основные экспортные конструкции GitBook: изображения, ссылки, content-ref, embed, hint, stepper/step, details, заголовки, списки, цитаты и код.
