# Кастомные картины

<details>

<summary><mark style="color:$primary;">Как загрузить собственную картинку на сервер?</mark></summary>

#### Способ #1

<ol><li>Вставь рамки на блоки, куда нужно разместить изображение</li><li>Пропиши команду <a href="#copy" title="Нажмите, чтобы скопировать"><span style="color:rgb(0, 255, 119)">/if select</span></a> для выбора рамок, куда нужно вставить картинку</li><li>Пропиши <span style="color:rgb(0, 255, 119)">/imageframe create &lt;название&gt; <ccылка> selection</ccылка></span><ccылка>, чтобы изображение сразу встало на выбранные рамки</ccылка></li></ol>

#### Способ #2

<ol><li>Вставь рамки на блоки, куда нужно разместить изображение</li><li>Пропиши команду<span style="color:rgb(0, 255, 119)"> /imageframe create &lt;название <ccылка> &lt;ширина в блоках&gt; &lt;высота в блоках&gt; combined</ccылка></span><ccылка></ccылка></li><li>Полученное изображение будет в инвентаре. Чтобы его активировать, надо взять его в руки, и кликнуть им по рамке</li></ol>

</details>

{% hint style="info" color="#00ff77" %}
<p>Картинки могут пропасть/не загружаться, если на основном сервере они удалены. В качестве удобного загрузчика можете использовать обычные сообщения из Discord<br><br><br>Если Вы уверены, что изображение всё ещё находится на сервере, пропишите команду <mark style="color:$primary;">/if refresh <Имя></mark></p>
{% endhint %}

| Команда | Обозначение |
| --- | --- |
| /if select | Выбрать рамки, куда нужно разместить изображение |
| /imageframe create <название> selection | Загружает изображение по ссылке в выбранные рамки |
| /imageframe create <название> <ширина> <высота> combined | Загружает изображение по ссылке в инвентарь |
| /if clone <Имя> <Новое имя> selection | Клонирует изображение в выбранные рамки /if selection |
| /if clone <Имя> <Новое имя> combined | Клонирует изображение в инвентарь |
| /if refresh <Имя> <Новая ссылка> | Обновить ссылку на изображении |
| /if refresh <Имя> | Обновить картинки с указанным именем |
| /if get <Имя> selection | Загружает существующее изображение в выбранные рамки /if selection |
| /if get <Имя> combined | Загружает существующее изображение в инвентарь |
| /if list | Список загруженных изображений |
| /if rename <Имя ><Новое имя> | Переименовать изображение |
| /if delete <Имя> | Удалить изображение |
