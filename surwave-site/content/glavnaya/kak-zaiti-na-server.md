## Первый заход на сервер

Чтобы зайти на сервер, зайди в игру, выбери "Сетевая игра" и добавляй наш IP!

<figure><img src="../.gitbook/assets/image (232).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Для входа на сервер необходимо ввести один из двух наших IP

* **espolit.ru**
* **espolit.online**
{% endhint %}

## Лобби

* ### **Регистрация**

Для того, чтобы зарегистрироваться, Вам нужно ввести команду <mark style="color:$primary;">/reg <пароль> <повтор\_пароля></mark>

<figure><img src="../.gitbook/assets/image (221).png" alt=""><figcaption></figcaption></figure>

После, этот пароль будет требоваться для входов. Команда для входа - <mark style="color:$primary;">/login <пароль</mark>

* ### **Вход на сервер**

<figure><img src="../.gitbook/assets/image (208).png" alt=""><figcaption></figcaption></figure>

Для входа на сервер вы можете использовать как предмет, который Вам выдали при входе, так и стоящего <mark style="color:$primary;">NPC за барной стойкой</mark>!

У бармена и предмета откроется меню выбора сервера, смело выбирай <mark style="color:$primary;">**ESPOLIT**</mark>!

<figure><img src="../.gitbook/assets/image (209).png" alt=""><figcaption></figcaption></figure>
