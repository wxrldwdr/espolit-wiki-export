# Табличные механики

### Лифт

{% stepper %}
{% step %}
#### Поставить две таблички друг на другом

Таблички должны находиться ровно друг под другом чтобы лифт работал
{% endstep %}

{% step %}
#### Освободи территорию

Убедись что возле таблички нет сторонних блоков, иначе игрок не сможет нажать на табличку, а так же на уровне табличке должна быть твёрдая поверхность
{% endstep %}

{% step %}
#### Напиши <mark style="color:$primary;">\[Lift Down]</mark> на верхней табличке

<figure><img src="../../.gitbook/assets/image (163).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Напиши <mark style="color:$primary;">\[Lift Up]</mark> на нижней табличке

<figure><img src="../../.gitbook/assets/image (162).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
#### Готово!

Игроки могут пользоваться лифтом!
{% endstep %}
{% endstepper %}

### Редактирование табличек

С помощью <mark style="color:$primary;">Shift+ПКМ</mark> на табличку так же можно редактировать содержимое таблички.

{% hint style="info" %}
Таблички в городах не получится редактировать, если вы не являетесь жителем этого города
{% endhint %}
