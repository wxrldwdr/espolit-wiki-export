# Городские роли

## Изменить городскую роль

|                                                                                |                                            |
| ------------------------------------------------------------------------------ | ------------------------------------------ |
| <mark style="color:$primary;">/t rank add <Ник игрока> <Название Ранга></mark> | Выдать игроку городскую роль               |
| <mark style="color:$primary;">/t rank add <Ник игрока> <Название Ранга></mark> | Убрать у игрока городскую роль             |
| <mark style="color:$primary;">/t ranklist</mark>                               | Посмотреть лист игроков с правами в городе |

## Возможности городских ролей

{% tabs %}
{% tab title="Ассистент" %}
Идентификатор - <mark style="color:$primary;">assistant</mark>



* Приват/Расприват участков
* Выселять игроков
* Переключение Публичный город или нет
* Доступ к городскому складу
* Выдавать участок во владение
* Просмотр городского налога и возможность его оплаты
* Управление  городскими правами
* Общий набор участников
* Управление территориальными претензиями
* Доступ к городскому инвентарю
* Просмотр логов городского инвентаря
* Доступ к меню Освоения
* Телепортировать в город игроков не смотря на Публичность города
* Доступ к строительству в городе
* Доступ к ломанию блоков в городе
* Доступ к переключению предметов в городе
* Доступ к использованию предметов в городе
* Доступ к городским религиям
{% endtab %}

{% tab title="Казначей" %}
Идентификатор - <mark style="color:$primary;">treasurer</mark>



* Доступ к городскому складу
* Просмотр городского налога и возможность его оплаты
* Доступ к городскому инвентарю
* Просмотр логов городского инвентаря
{% endtab %}

{% tab title="Командир" %}
Идентификатор - <mark style="color:$primary;">commander</mark>



* Возможность объявлять рейд
* Возможность объявлять завоевание
* Управление территориальными претензиями
* Взаимодействия с врагами города
* Взаимодействия с альянсами
{% endtab %}

{% tab title="Строитель" %}
Идентификатор - <mark style="color:$primary;">builder</mark>



* Доступ к строительству в городе
* Доступ к ломанию блоков в городе
* Доступ к переключению предметов в городе
* Доступ к использованию предметов в городе
{% endtab %}
{% endtabs %}
