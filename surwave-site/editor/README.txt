SURWAVE WIKI EDITOR

ЗАПУСК
1. Из корня проекта запусти START_EDITOR.bat.
2. Редактор откроется локально в браузере.
3. Для обычного просмотра Wiki используй START_SURWAVE_WIKI.bat.

ВОЗМОЖНОСТИ
- Открытие всех существующих страниц из surwave-site/content/.
- Создание, дублирование и удаление страниц.
- Выбор раздела Wiki и имени файла без ручного изменения site-data.json.
- Визуальное редактирование текста: жирный, курсив, подчёркивание, зачёркивание, код, выделение, ссылки.
- Заголовки H1-H6.
- Картинки и медиа с загрузкой прямо через редактор.
- Маркированные и нумерованные списки.
- Окошки info / warning / success / danger.
- Раскрывающиеся блоки details.
- Пошаговые инструкции stepper с отдельными шагами 1, 2, 3, 4 и вложенными блоками.
- Карточки внутренних ссылок.
- Внешние embed-ссылки.
- Цитаты, таблицы, код и разделители.
- Перетаскивание, стрелки вверх/вниз, дублирование и удаление блоков.
- Живой предпросмотр справа.
- Ctrl+S для сохранения.
- Скачать исходный .md.
- Скачать автономный .html с локальными изображениями, встроенными внутрь файла.

КУДА СОХРАНЯЕТСЯ
Страницы: surwave-site/content/
Обёртки сайта: surwave-site/wiki/
Загруженные картинки/медиа: .gitbook/assets/
Навигация: surwave-site/assets/js/site-data.json

Редактор и API работают только через локальный сервер на 127.0.0.1.
